ForceAtlas2, running — the graph opening up

474 nodes · 828 edges · 16 frames · 600 iterations of Gephi's own ForceAtlas2, 40 iterations per frame. All frames are drawn in one fixed coordinate system, so the expansion you see is real motion rather than a re-fit of the view each time.

What this shows, and what it does not. The nodes genuinely push each other apart — overlap goes from 0.565% to 0.33%. What it does not show is a clean map: the nearest-neighbour distance only moves from 1.54 px to 1.17 px, so on a 1600×1000 canvas the settled graph remains denser than one node diameter. Watching it open is the right way to see the algorithm work; it is not by itself a cure for density.

Reproduce

PYTHONPATH=. python tools/make_animation.py 600 40 3 runs the Toolkit and writes the frames; python tools/make_animation_html.py writes this page. Add ?static&frame=12 to freeze on one frame.
